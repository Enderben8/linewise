# Project instructions

This folder is for rebuilding the features of Memorize By Heart as a new app. The full spec is in @SPEC.md. Read it before starting any task.

- Follow the ground rules in SPEC.md §1. Never read secrets out of the `.apk` file, copy them or commit them.
- Work through the phases in SPEC.md §11 in order. Tick checkboxes as you finish them.
- If you change a default or make a decision the spec does not cover, add a row to SPEC.md §10.
- Before you call a task done, run `npx tsc --noEmit` and the tests.
